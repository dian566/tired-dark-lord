## What it does

`main.py` writes a 99-word villain monologue (496 characters) to `/output/entry.txt`:

Veyra, ringer of the Hollow Bell, has rung it twelve times — each ring
making the kingdom forget a little more of itself — and one more ring at
the eclipse will make the sun forget to rise. Her tiredness is never
named: it lives in the pauses, the abandoned kettle, and the counting of
chimes, ending on the sting that she is waiting for the dark to finally
keep her.

The program is fully deterministic: it writes the same 496 characters on
every run, with no randomness, no clock, and no network.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
