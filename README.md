## What it does

Running `main.py` drops a 99-word villain monologue (496 characters) into
`/output/entry.txt`:

Veyra, keeper of the Hollow Bell, has tolled it twelve times — each toll
making the realm forget a little more of itself — and a final toll at the
eclipse would make the sun forget to rise. What wears her down is never
spelled out: it leaks through the pauses, the kettle left empty, and the
chimes she keeps count of, closing on the sting that she waits for the dark
to finally keep her.

The script is fixed and repeatable: it prints the same 496 characters on
every run, with no randomness, no clock, and no network access.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
